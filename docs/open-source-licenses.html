Pheeeew 오픈소스 라이선스

최종 수정일: 2026년 9월 1일

Pheeeew는 다음 오픈소스 소프트웨어와 공개 지도 데이터를 사용합니다. 각 저작권은 해당 저작권자에게 있으며, 각 구성요소는 표시된 라이선스 조건에 따라 제공됩니다.
