# Google Play 데이터 보안 답변 초안

이 초안은 2026-09-01 현재 저장소의 출시 의존성과 구현을 기준으로 합니다. Play Console 제출 직전에 실제 릴리스 AAB와 서버 동작을 다시 확인해야 합니다.

## 현재 구현 기준

- 위치 권한: `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`
- 위치 접근: 사용자가 현재 위치 기능을 실행할 때의 단발성 포그라운드 접근
- 기기 위치 영구 저장: 없음
- 운영자 서버로 기기 위치 전송: 없음
- 지도 서비스: OpenFreeMap 스타일·타일을 HTTPS로 요청
- 계정, 광고, 광고 ID, 결제, 분석, 크래시 수집, 푸시: 없음

## 제출 시 유의할 판단

Google Play의 “수집”은 일반적으로 앱 또는 앱에 포함된 SDK가 데이터를 기기 밖으로 전송하는 경우를 포함합니다. GPS 좌표는 운영자 서버나 OpenFreeMap에 직접 전송하지 않지만, 지도 요청의 타일 좌표로 사용자가 보고 있는 지역을 추정할 수 있고 OpenFreeMap/Cloudflare가 네트워크 정보를 처리할 수 있습니다.

따라서 다음 두 해석 중 실제 릴리스 동작과 Google Play의 당시 안내에 맞는 답을 선택해야 합니다.

1. GPS 위치가 기기 안에서만 처리되고 지도 타일 요청을 기기 위치 수집으로 보지 않는 경우: 위치 데이터 “수집하지 않음”.
2. 현재 위치로 이동한 뒤의 타일 요청이 위치 정보의 기기 외 전송에 해당한다고 보수적으로 판단하는 경우: 대략적/정확한 위치 “수집”, 목적 “앱 기능”, 처리 “일시적”, 필수 여부 “선택”; 서비스 제공자 처리 여부에 따라 공유 항목을 검토.

잘못된 단정은 정책 위반이 될 수 있으므로, 서버 기능이 연결된 뒤 Play Console 도움말의 최신 정의와 지도 제공자의 당시 데이터 처리 방침을 기준으로 최종 확정합니다.
